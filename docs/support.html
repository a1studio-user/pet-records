技术支持

使用宠刻时遇到问题，可以通过下方入口提交反馈。请说明设备型号、系统版本、问题发生页面与复现步骤。

提交技术支持问题
GitHub Issues 是公开页面，请勿填写 Apple ID、邮箱、宠物分享码、照片或其他个人敏感信息。

常见问题

如何恢复数据？
使用原来的 Apple 账号登录，App 会在启动后静默同步云端记录。

如何共同饲养？
主饲养员在宠物档案编辑页查看八位分享码；另一位用户在“宠物”页选择“使用分享码添加”。

为什么共同饲养员不能编辑档案？
宠物档案和分享权限属于首次创建宠物的主饲养员，共同饲养员仍可维护生活记录。

如何删除账号？
进入“账号”，选择“删除账号及数据”，按提示再次通过 Apple 授权并确认。

服务范围

宠刻仅保存用户主动录入的信息，不提供诊断、用药、疫苗或其他医疗建议与判断。
