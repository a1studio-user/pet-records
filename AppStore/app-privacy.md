# App Store 隐私标签填写表

App Store Connect 首题选择：**是，我们会从此 App 收集数据**。

以下数据均仅用于“App 功能”，均与用户身份关联，均不用于跟踪：

| App Store 数据类型 | 本 App 中的对应内容 | 用途 | 与身份关联 | 跟踪 |
| --- | --- | --- | --- | --- |
| 联系信息 → 姓名 | Apple 首次授权时可能提供的显示名称 | App 功能 | 是 | 否 |
| 联系信息 → 电子邮件地址 | Apple 提供的真实或中转邮箱 | App 功能 | 是 | 否 |
| 标识符 → 用户 ID | Apple/Supabase 稳定账号标识 | App 功能 | 是 | 否 |
| 用户内容 → 照片或视频 | 用户主动选择的宠物头像、产品照片 | App 功能 | 是 | 否 |
| 用户内容 → 其他用户内容 | 宠物档案、驱虫/疫苗/主粮/口味/洗澡记录、分享成员关系 | App 功能 | 是 | 否 |

不选择：精确位置、联系人、健康与健身、财务信息、浏览历史、搜索历史、购买项目、使用数据、诊断数据、广告数据、敏感信息。

补充答案：

- 是否用于第三方广告：否
- 是否用于开发者广告或营销：否
- 是否用于分析：否
- 是否用于产品个性化：否
- 是否与数据经纪人共享：否
- 是否用于跨 App 或网站跟踪：否
- 第三方处理者：Supabase，仅提供认证、数据库和私有对象存储

若今后加入社区、分析 SDK、崩溃收集、推送统计或广告，必须在发布对应版本前更新此表和 App Store Connect 的隐私答案。
