# App Review 审核备注（中文稿）

宠刻是一款猫狗生活记录工具，不提供诊断、用药建议、疫苗建议或任何医疗判断。药品和疫苗名称仅由用户选择或输入，用于保存历史记录。

测试说明：

1. App 必须使用系统“通过 Apple 登录”后才能进入；没有游客模式或邮箱密码登录。
2. 登录后，在“宠物”页新建宠物；保存后进入该宠物的“编辑”页面，底部可查看系统自动生成的八位分享码。
3. App 在启动、回到前台以及用户保存修改后自动进行后台同步，界面不会显示同步页面或进度。
4. 驱虫、疫苗、主粮、口味和洗澡记录可从底部“新增”入口创建；生活记录支持左滑编辑和删除。
5. 另一账号可在“宠物”页点击“使用分享码添加”加入共同饲养。共同饲养员能管理记录，但无法编辑宠物档案或查看/再次分享代码。
6. “账号”页面提供“退出账号”和“删除账号及数据”。用户确认删除后需再次使用当前 Apple 账号授权；服务端先撤销 Apple 登录凭据，再永久删除账号、其主养宠物、关联记录和云端照片。
7. 相机和相册权限只在用户主动点击对应按钮时请求；两种方式互为独立选择。

无需付费或订阅，无广告，无 App 内购买。

提交前检查：Supabase Apple Provider 已开启；审核环境可访问 Supabase；`delete-account` Edge Function 已部署；隐私政策 URL 与支持 URL 可公开访问。
